# Общее меню DN1SUP для расширения Comp Add View

## Суть изменения

Сейчас пункты расширения живут в «Расширения → ComponentAddViews» (`UI.menu('Plugins').add_submenu('ComponentAddViews')` в `su_component_add_view/main.rb:30`). Меняем на **меню верхнего уровня `DN1SUP`**, общее для всех расширений DN1SUP, с подменю **«Comp Add View»** внутри.

Ключевой факт API: `UI.menu` с неизвестным именем создаёт новое меню верхнего уровня, а повторный вызов с тем же именем возвращает уже существующее — поэтому меню автоматически становится общим: когда другие расширения DN1SUP вызовут `UI.menu('DN1SUP')`, они добавят свои подменю в то же меню, рядом с «Comp Add View». (Меню появится в конце строки меню, после «Справка» — позицию API менять не позволяет.)

## Правки

### 1. `su_component_add_view/main.rb` (строки 29–34)

Заменить:
```ruby
# Пункты в меню «Расширения» (Plugins)
menu = UI.menu('Plugins').add_submenu('ComponentAddViews')
```
на:
```ruby
# Общее меню верхнего уровня DN1SUP — разделяется всеми расширениями DN1SUP:
# UI.menu создаёт его при первом вызове и возвращает уже созданное при повторных
dn1sup_menu = UI.menu('DN1SUP')

# Пункты расширения — в подменю «Comp Add View» внутри DN1SUP
menu = dn1sup_menu.add_submenu('Comp Add View')
```
Далее без изменений: `add_item(cmd_rotate)`, `add_item(cmd_views)`, разделитель, «Настройки...».

Тулбар `ComponentAddViews` не трогаю (не просили; переименование к тому же сбросило бы сохранённое положение панели).

### 2. `su_component_add_view.rb:14` — версия 1.1.0 → 1.2.0 (видимое пользователем изменение UI).

### 3. `README.md` — обновить пути меню:

- строки 70, 72, 75: «Расширения → ComponentAddViews → …» → «DN1SUP → Comp Add View → …»;
- строка 94: версия 1.2.0.

## Вне рамок (возможный следующий шаг)

В монорепозитории `dn1sup_extensions` есть более новый порт этого же плагина и ещё 3 расширения DN1SUP — каждое сейчас создаёт своё подменю «DN1Sup …» в «Расширения». Перевести их всех на общий верхний уровень `DN1SUP` — отдельная задача в том репозитории, могу сделать после.
