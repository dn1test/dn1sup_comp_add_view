# Component Rotator (Left & Z-X) for SketchUp

Плагин (расширение) для Trimble SketchUp, предназначенный для быстрого создания копии выбранного компонента или группы со сдвигом влево на габаритную ширину и последующим поворотом вокруг осей Z и X.

---

- **Гибкий режим работы**: возможность выбора в настройках — создавать копию слева от объекта или поворачивать исходный объект на месте.
- **Автоматический расчет сдвига**: при создании копии объект смещается влево (по оси `-X`) ровно на свою габаритную ширину (`bounds.width`).
- **Последовательный поворот**: трансформация выполняется сначала вокруг оси **Z**, затем вокруг оси **X** относительно точки вставки объекта.
- **Поддержка компонентов и групп**: одинаково корректно работает как с `Sketchup::ComponentInstance`, так и с `Sketchup::Group`.
- **Сохранение параметров**: углы поворота и режим создания копии сохраняются в настройках SketchUp (`Sketchup.read_default` / `Sketchup.write_default`) между сессиями.
- **Поддержка отмены**: вся операция дублирования и вращения выполняется внутри единой транзакции (`model.start_operation`), что позволяет отменить действие в один клик через `Ctrl + Z`.
- **Удобный интерфейс**: быстрый доступ через меню «Расширения» (`Plugins`) и кнопку на панели инструментов (`Toolbar`) с векторной SVG-иконкой.

## 🚀 Установка

### Вариант 1: Прямое копирование в папку Plugins

1. Скопируйте файл `su_comp_rotate.rb` и папку `su_comp_rotate/` в директорию плагинов вашей версии SketchUp:
   - **Windows**: `%AppData%\SketchUp\SketchUp <Версия>\SketchUp\Plugins\`
   - **macOS**: `~/Library/Application Support/SketchUp <Версия>/SketchUp/Plugins/`
2. Перезапустите SketchUp или загрузите файл через Ruby Console:
   ```ruby
   load 'su_comp_rotate.rb'
   ```

### Вариант 2: Упаковка в `.rbz` архив

1. Выделите файл `su_comp_rotate.rb` и папку `su_comp_rotate/`.
2. Запакуйте их в ZIP-архив.
3. Переименуйте расширение архива с `.zip` на `.rbz` (например, `su_comp_rotate.rbz`).
4. В SketchUp откройте: **Окно (Window) → Диспетчер расширений (Extension Manager) → Установить расширение (Install Extension)** и выберите созданный файл `.rbz`.

## 🛠 Использование

1. Выделите один или несколько компонентов/групп в модели SketchUp.
2. Для настройки параметров:
   - Откройте меню **Расширения → Копия слева и Поворот Z-X → Настройки...**
   - В выпадающем списке выберите, нужно ли **Создавать копию слева** (`Да` / `Нет`).
   - Задайте углы поворота по осям Z и X в градусах.
3. Для выполнения операции:
   - Выберите пункт меню **Расширения → Копия слева и Поворот Z-X → Повернуть** или нажмите кнопку на панели инструментов **«Копия слева + Поворот»**.
