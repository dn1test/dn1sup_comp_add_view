# DN1Sup Component Add View (Copy, Rotate & Views) for SketchUp

Плагин (расширение) для Trimble SketchUp, предназначенный для быстрого создания копий выбранного компонента или группы со сдвигом влево и поворотом по осям Z и X, а также генерации ортогональных проекций (вид сверху и вид сбоку).

---

- **Гибкий режим работы**: возможность выбора в настройках — создавать копию слева от объекта или поворачивать исходный объект на месте.
- **Создание 2 проекционных копий (Вид сверху и Вид сбоку)**: отдельная операция в панели управления для мгновенной генерации двух повернутых проекций по стандарту чертежной раскладки:
  - **Вид сверху**: поворот по X на +90° и размещение **сверху** от исходного объекта (+Z).
  - **Вид сбоку**: поворот по Z на -90° (для вида справа) или +90° (для вида слева) и размещение **справа** от исходного объекта (+X).
- **Выбор проекции вида сбоку**: возможность в настройках выбрать, какой вид сбоку проецировать — **«Справа»** или **«Слева»**.
- **Универсальный адаптивный отступ**: автоматический расчет расстояния между проекциями:
  - В процентах от габарита объекта (например, **`20%`**) — сохраняет идеальные визуальные пропорции как на мелких деталях (50 мм), так и на крупных конструкциях (3000 мм).
  - В точных единицах модели (например, **`150`** мм) при необходимости фиксированного шага.
- **Автоматический расчет сдвига**: при создании копии объект смещается влево (по оси `-X`) ровно на свою габаритную ширину (`bounds.width`).
- **Последовательный поворот**: трансформация выполняется сначала вокруг оси **Z**, затем вокруг оси **X** относительно точки вставки объекта.
- **Поддержка компонентов и групп**: одинаково корректно работает как с `Sketchup::ComponentInstance`, так и с `Sketchup::Group`.
- **Сохранение параметров в YAML**: все настройки сохраняются в конфигурационном файле `settings.yaml` в формате YAML.
- **Поддержка отмены**: вся операция выполняется внутри единой транзакции (`model.start_operation`), что позволяет отменить действие в один клик через `Ctrl + Z`.
- **Удобный интерфейс**: управление и настройки — в GUI-панели (UI::HtmlDialog на Vue 3 + Tailwind) с живыми SVG-схемами предпросмотра; на тулбаре одна кнопка открытия панели, доступ и через меню `Расширения → DN1Sup → Comp Add View`.

## 📂 Структура проекта

Проект организован в соответствии с официальными стандартами **SketchUp Developer Guidelines** и **RuboCop-SketchUp**:

```text
dn1sup_comp_add_view/
├── README.md                          # Документация проекта
├── dn1sup_comp_add_view.rb           # Корневой регистратор SketchupExtension
├── frontend/                          # Исходники панели (Vue 3 + Tailwind, в .rbz не попадает)
│   ├── src/                           #   App.vue, компоненты схем и настроек, мост к Ruby
│   └── vite.config.js                 #   Сборка в один файл resources/panel.html
└── dn1sup_comp_add_view/             # Папка модуля расширения
    ├── main.rb                        # Точка входа, меню и тулбар (кнопка панели)
    ├── dialog.rb                      # Панель управления (UI::HtmlDialog + колбэки + SelectionObserver)
    ├── rotator.rb                     # Бизнес-логика дублирования, сдвига, вращения и проекций
    ├── settings.rb                    # Логика чтения/записи настроек
    ├── settings.yaml                  # Локальные настройки (в .rbz не поставляется)
    └── resources/                     # Ресурсы
        ├── panel.html                 # Собранная панель (Vue 3 + Tailwind, один файл)
        └── panel.svg                  # Иконка кнопки открытия панели
```

### Сборка панели (frontend/)

Панель написана на Vue 3 + Tailwind CSS и собирается Vite в единый
self-contained `dn1sup_comp_add_view/resources/panel.html` (JS и CSS инлайнятся —
HtmlDialog работает офлайн). Требуется Node.js:

```bash
cd frontend
npm ci
npm run build
```

## 🚀 Установка

### Вариант 1: Прямое копирование в папку Plugins

1. Скопируйте файл `dn1sup_comp_add_view.rb` и папку `dn1sup_comp_add_view/` в директорию плагинов вашей версии SketchUp:
   - **Windows**: `%AppData%\SketchUp\SketchUp <Версия>\SketchUp\Plugins\`
   - **macOS**: `~/Library/Application Support/SketchUp <Версия>/SketchUp/Plugins/`
2. Перезапустите SketchUp или загрузите файл через Ruby Console:
   ```ruby
   load 'dn1sup_comp_add_view.rb'
   ```

### Вариант 2: Упаковка в `.rbz` архив

1. Выделите файл `dn1sup_comp_add_view.rb` и папку `dn1sup_comp_add_view/`.
2. Запакуйте их в ZIP-архив.
3. Переименуйте расширение архива с `.zip` на `.rbz` (например, `ComponentAddViews.rbz`).
4. В SketchUp откройте: **Окно (Window) → Диспетчер расширений (Extension Manager) → Установить расширение (Install Extension)** и выберите созданный файл `.rbz`.

## 🛠 Использование

1. Выделите один или несколько компонентов/групп в модели SketchUp.
2. Откройте **панель управления**: кнопка на панели инструментов `DN1Sup Comp Add View` или меню **Расширения → DN1Sup → Comp Add View → Панель...**.
3. **Копия слева и поворот по Z и X** — кнопка **«Повернуть»** в панели (схема слева показывает, куда сдвинется и как повернётся копия при текущих углах).
4. **Создание копий вида сверху и сбоку** — кнопка **«Создать проекции»** (схема показывает раскладку: вид сверху — сверху, вид сбоку — справа или слева, с отступом).
   - Копия вида сверху размещается сверху от объекта (+Z), а копия вида сбоку — справа (+X) с автоматическим адаптивным отступом.
5. **Настройки** — внизу панели, с индикатором «не сохранено»:
   - **Создавать копию слева** (переключатель).
   - **Углы поворота по осям Z и X** в градусах (поле + слайдер).
   - **Вид сбоку (проекция)** (`Справа` / `Слева`).
   - **Отступ проекций (% или мм)** (например, `20%` или `150`).
   - Все схемы предпросмотра реагируют на изменение настроек мгновенно.
