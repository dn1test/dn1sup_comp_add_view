# CHANGELOG — DN1Sup Component Add View

Все заметные изменения проекта фиксируются в этом файле.
Формат записей — по образцу [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/):
новые версии добавляются **сверху**, каждая запись начинается с заголовка версии и даты.

## Правила версионирования (X.Y.Z)

Формат версии: `X.Y.Z`.

| Цифра | Когда меняется |
|-------|----------------|
| **X** (первая) | Только по явному запросу владельца проекта |
| **Y** (вторая) | Большие (заметные) изменения: новая функциональность, существенная переработка |
| **Z** (третья) | Мелкие недочёты: исправления ошибок, косметика, мелкие улучшения |

При изменении версии необходимо:

1. Обновить версию в `su_component_add_view.rb` (`extension.version`), `su_component_add_view/main.rb` (`VERSION`), `README.md` («Версия») и `registry.json` (при сборке `ruby tools/pack.rb` выровняет `registry.json` автоматически).
2. Добавить запись в этот файл сверху, в одном из разделов ниже.
3. Для публикации — тег `v<версия>` (например, `v0.4.1`): GitHub Actions соберёт `.rbz` и создаст релиз.

### Разделы записи

- **Добавлено** — новая функциональность.
- **Изменено** — изменения в существующем поведении.
- **Исправлено** — исправления ошибок.

## [0.4.1] — 2026-10-09

### Изменено

- Обновлён общий `dn1sup_updater.rb` (из репозитория Extension Store): обновления распознаются не только по номеру версии, но и по дате публикации релиза — по дате установки текущей сборки (пишется при установке через апдейтер/Store).

### Примечание

- Снимает ограничение из примечания к 0.4.0: пользователи с установленной версией 1.4.0 теперь получат предложение установить 0.4.1 — релиз новее по дате публикации, хотя номер ниже (смена схемы нумерации).

## [0.4.0] — 2026-10-09

### Изменено

- Введены правила версионирования `X.Y.Z` и настоящий файл изменений (CHANGELOG.md).
- Старшая цифра версии сброшена 1 → 0 по решению владельца проекта. По функциональности версия соответствует 1.4.0; история до 0.4.0 в changelog не ведётся.

### Примечание

- Пользователям с установленной версией 1.4.0 автообновление не предложит 0.4.0 (обновление сравнивает версии численно); новые установки получат 0.4.0.
